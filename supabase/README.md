# 歲時錄 V2 資料庫腳本

此目錄僅保留現行固定共用帳本所需的 SQL。請在自己的 Supabase SQL Editor 執行，請勿提交任何連線金鑰或帳號資料。

| 檔案 | 用途 | 何時執行 |
| --- | --- | --- |
| `歲時錄-v2-乾淨重設.sql` | 建立 V2 資料表、RLS、LWW 帳務 RPC、憑據流程與固定八項大目。**會刪除歲時錄既有資料。** | 僅限新空白專案。 |
| `歲時錄-v2-固定共用帳本.sql` | 將玉瑟、石琴固定指向同一冊「歲時錄 · Vellum Tides」，並補足憑據寫入權限。 | 新建 V2 後；可重複執行。 |
| `歲時錄-v2-帳頁分段與備份.sql` | 建立伺服器端帳頁分段、摘要、完整匯出及僅追加式還原 RPC。 | 現有帳本要啟用新版帳頁翻閱與帳本典藏時。 |
| `歲時錄-v2-典藏快照與永久刪除.sql` | 讓完整備份僅收錄有效帳頁；新增備份快照還原、已收起帳頁永久清除，以及安全補入時重新啟用備份內已收起帳頁的修復。 | 已啟用帳頁分段與典藏後，要使用快照還原、永久清除或安全補入修復時；可重複執行。 |
| `歲時錄-v2-核對.sql` | 唯讀核對核心資料表、索引、觸發器、RLS 及既有帳務 RPC。 | 新建 V2 後或排除資料庫問題時。 |

## 日常更新

若目前帳本已能登入、添新帳與憑據入冊，且**尚未**啟用帳頁分段與典藏，請依序執行：

```text
歲時錄-v2-帳頁分段與備份.sql
歲時錄-v2-典藏快照與永久刪除.sql
```

若已執行過 `歲時錄-v2-帳頁分段與備份.sql`，只需執行：

```text
歲時錄-v2-典藏快照與永久刪除.sql
```

執行後重新整理網站。帳頁翻閱維持分段載入；「簿冊規制」的帳本典藏會提供「安全補入」、「還原至備份快照」與「永久清除已收起帳頁」。安全補入不覆寫仍有效資料，但會重新啟用備份內、目前僅被收起的同識別碼帳頁；快照還原會依使用者選擇覆寫資料；永久清除則無法復原。三者都應先下載最新備份並確認兩台裝置同步後使用。
